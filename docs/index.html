Why

Cropping icons by hand doesn't scale

Pulling assets out of a brochure or configurator mockup used to mean a lot of careful, repetitive work for every file.

By hand

  • Reading pixel coordinates off a rendered page to find each icon's centre.
  • Tuning a crop radius per batch so nearby label text doesn't bleed in.
  • Re-rendering a contact sheet after every attempt to catch bad crops.
  • Working around .ai files that arrive corrupted after a chat upload.

With SVG Extractor

  • Spatial clustering finds each asset. No coordinates to guess.
  • Label detection keeps outlined text out of the crop, and uses live text to name the file.
  • A contact sheet comes with every export, and the review UI shows the real crops as you work.
  • Reads files straight off disk, treating PDF-compatible .ai as PDF.

How it works

From one sheet to a folder of assets in four steps

One CLI command runs all four. The review UI sits on top and edits the same session file, so you can correct the result before exporting.

Parse

Walks the PDF operator list with PDF.js, tracking transforms, colours, strokes and clips. Every painted path comes out with an exact bounding box.

Classify

Sorts elements into backgrounds, dividers, specks, text and geometry. Outlined lettering is spotted as runs of small glyph-like shapes on a shared baseline.

Cluster

Groups geometry that sits within a gap of each other, orders assets in reading order, and pairs each with the nearest label below or above it.

Export

Writes each asset's paths verbatim into a tight viewBox, so strokes scale exactly. PNGs are rasterised from that same SVG. You also get a manifest and a contact sheet.

Review UI

Check and fix the crops before you export

Detection is a heuristic, so the browser UI makes fixing it fast. The page is drawn by PDF.js, so what you see is exactly what's in the file.

  • Merge, split, exclude

    Shift-click boxes and press M, S or X. A split re-clusters the box at half the gap.

  • Draw or resize a box

    Drag on the page to take whatever is mostly inside the box, or drag a corner to adjust a detected one.

  • Undo anything

    ⌘Z reverts the last edit, including a batch delete. Every change saves to the session file as you go.

  • Copy or download one asset

    Each thumbnail is the real exported SVG. Copy its markup straight into code or a design tool, or download a single SVG or PNG.

Features

Built for real mockup sheets

Exact geometry

Paths, transforms and clip paths are copied verbatim from the source, not traced or redrawn, so stroke widths and curves match the original.

Label-aware

Outlined captions are kept out of the crop. Live text becomes the file name, so STANDARD exports as standard.svg.

Everything you need, in one export

SVGs, PNGs at any scale, a manifest.json listing each asset's size and colours, and a _contact-sheet.png. Download it as one .zip.

CLI for batch runs

detect, export, inspect and serve. The CLI and the UI share one session file, so corrections made in the browser carry into scripted exports.

Tunable

Every threshold (gap, padding, glyph size, background area) can be set per run with --gap or --set key=value, or per page in the UI.

Stays on your machine

No uploads to a service. The server listens on 127.0.0.1 only and refuses requests from other websites, so client artwork never leaves your computer.

Get started

Up and running in a minute

Clone the repository, install, and open the review UI. Drop in an .ai or PDF and you'll see the detected assets right away.

1 · Install

Pure JavaScript apart from one prebuilt binary, so there's nothing to compile.

$ git clone \
    https://github.com/cabanas-engg/svg-extractor
$ cd svg-extractor
$ npm install

2 · Open the UI

Starts the local server and opens your browser. Drag a file onto the page.

$ npm run serve
# → http://127.0.0.1:5178

3 · Or script it

Detect and export in one go: SVG and PNG at 4×, plus the manifest and contact sheet.

$ node bin/svg-extractor.js \
    export sheet.ai -o icons/ \
    --format svg,png \
    --scale 4

Needs Node 20+. .ai files must be saved with Create PDF Compatible File, which is Illustrator's default.

Honest limits

What it doesn't do (yet)

Working well on outlined, flattened artwork isn't the same as solving every file. These are the known gaps.

  • Telling text from icons is a heuristicA tight row of three or more small, varied shapes can read as a word. Very large display type reads as geometry.
  • Outlined labels can't name filesOutlined text has no string to read, so those assets get grid names like p1_r2_c3. OCR isn't built yet.
  • Dense layouts need a handIcons that touch each other or their labels can merge into one box. Split, draw and resize in the UI fix it.
  • Some effects are approximatedGradients become a solid colour, smooth shadings, blend modes and soft masks are skipped. Every case is flagged as a warning, never silently.
